# ZstdNet Cleanroom — Alpha 1

首个公开 alpha 版本：将 ZstdNet 向后移植到 **Minecraft 1.12.2 / Cleanroom / Java 25**。

## 安装

- 需要 Cleanroom；已验证的版本为 **0.6.10-alpha**，使用 **Java 25**。不适用于传统 Forge 1.12.2 / Java 8。
- 下载本页的 `zstdnet-1.12.2-cleanroom-1.4.7-cleanroom-alpha.1.jar`，放入客户端和服务端的 `mods`。升级时移除旧版 ZstdNet JAR，避免重复加载。
- JNI 已完整内嵌，无需单独安装。建议 JVM 参数：`--enable-native-access=ALL-UNNAMED`。
- 配置及构建说明：[Cleanroom 使用文档](https://github.com/TheRealKamisama/zstdnet-cleanroom/blob/v1.4.7-cleanroom-alpha.1/mods/1.12.2/zstdnet-cleanroom/README.zh-CN.md)。本页同时提供 SHA256 校验文件；不要把 GitHub 自动生成的源码压缩包作为 Mod 安装。

## 包含功能与修复

- Zstd TCP 代理、UDP 原样透传、旧 FML 握手和服务端统计报告。
- 默认接管 Multiplayer / Direct Connect；内部回环连接具有重入保护，连接普通服务器时可关闭 Multiplayer proxy。
- 修复登录宣告与实际 Netty 压缩阈值不一致的问题；普通后端连接继续遵循 `server.properties`。
- HUD 上下行带宽自动缩放，修复 `/zstdnet config` 被聊天界面立即关闭以及退出配置页断开代理的问题。
- 报表明确区分“压缩后剩余”和“节省流量”。

## 验证与 alpha 范围

此前本地 Windows x64 / Java 25 构建、29 项自动回归、生产重映射与内嵌 JNI 校验通过；本版本由 GitHub Actions 再次构建和校验后发布。压缩修复已通过实际 Minecraft 解码器、服务端管线阈值比对及三组共九次生产协议连接测试。用户已确认实际进服与压缩正常。

GUI 修复尚未完成自动图形界面验收；LAN、完整整合包、长时间负载及其他操作系统仍需验证。测试驱动不随发行 JAR 分发。压缩代理本身不提供身份认证；正式部署请遵循文档中的认证与后端隔离要求。

## English

First public alpha of the ZstdNet backport for **Minecraft 1.12.2 on Cleanroom / Java 25**. Install the production JAR on the client and server; traditional Forge 1.12.2 / Java 8 is not supported. Includes aligned compression thresholds, multiplayer connection interception, HUD/config fixes, and clearer report labels. The release is built and verified by GitHub Actions. LAN, full modpack compatibility, GUI acceptance, sustained load, and platforms beyond Windows x64 remain alpha validation work.
